⛔ Facebook watching is stopped
Facebook showed a security check, so Web Watcher stopped all Facebook activity and did not try to solve it — that's what protects the account. This stays stopped even if you restart the app. Open Facebook yourself (Connect Facebook below), clear the check and make sure the account looks healthy, then resume.

Notifications & Keys

Telegram alerts

Get a buzz on your phone the moment a match is found. In Telegram, message @BotFather, send /newbot, and paste the token it gives you below. Then open a chat with your new bot, send it any message, and click Detect to fill in your chat ID.
Text back and forth with The Watcher
Reply to your bot in Telegram and it answers — ask about your watches, change what it's looking for, or ask about a listing it just sent. Same assistant as the chat in this app, so it's one continuous conversation. Only your own chat can talk to it.
Extra Telegram chat IDs, separated by commas. The Chat ID above is always allowed — add another here so a second person (you and your buddy) can both talk to the bot. Anyone not listed is ignored, which matters because anyone who finds your bot can message it. To get someone's ID: have them message the bot, then press Detect.
After this many hours with nothing new (and no chat), the bot sends a short "still on watch" note and offers to broaden the search or vet a listing. 12 = twice a day, 6 = every few hours, 0 = never check in.

Facebook

Connect Facebook
Opens a browser window so you can log into Facebook once. The saved session is reused by watches that have "Use saved login profile" enabled (e.g. Marketplace). Log in, then close the window.

Claude (optional — faster, sharper matching)

Web Watcher runs fully on your own computer by default. If you have an Anthropic API key (from console.anthropic.com), you can let Claude rate listings — it's faster and its alerts are more accurate. Billed to your own key; leave this blank to stay 100% local.
Use Claude to rate listings
The per-check judge that decides which finds are worth alerting. Off = your local model does it.
Use Claude for the hard chat turns
Everyday chat (status checks, yes/no) stays on your fast local model — free. Only the harder turns — setting up or changing a watch — use Claude, so replies stay sharp while the bill stays tiny. Off = your local model answers everything. Respects your monthly cap.
How it picks a model
Automatic — there's nothing to choose. Every request runs on your local model first, free. The app then checks that answer, and only if it actually failed does it pay for Claude, starting at the cheapest model and going up only if that one fails too. So a working local model costs you nothing, and you never pay on a guess about whether a question was "hard". Rating listings always stays local — it runs on every listing of every sweep, which is how a budget disappears overnight.
Hit either cap and Web Watcher falls back to the local models until it resets — so the bill can't run past it. Set the monthly cap below what you've actually loaded: a cap equal to your balance only stops you once the money's already gone. The daily cap is the one that turns a runaway afternoon into a lost afternoon instead of a lost month.

Self-review

Your biggest local model reads back through the app's own conversations and reports where it went wrong — misunderstood a request, ignored part of one, contradicted itself, or answered confusingly. It's slow on purpose and runs entirely on your machine, so it costs nothing but GPU time, and it waits for a quiet moment rather than interrupting a sweep.

Browser

    

      

        
Show browser window

        
When on, a Chromium window opens during each watch run so you can watch the agent navigate and interact with the page.

      

      
    

    

      

        
Browse like a person

        
Types searches into the site's search box and scrolls with natural pauses instead of jumping straight to result URLs. Slower per check, but much harder for sites to flag. Fingerprint protection is always on regardless of this switch. Turn off only for simple sites that don't block bots.

      

      
    

    

      

        
Show agent cursor

        
Draws a red cursor in the agent's browser so you can watch where it clicks. Only visible when the browser is visible (turn off Headless above). Slightly reduces stealth, so keep it off for normal watching.

      

      
    


    

      

        
Reset to a fresh install

        
Permanently erases everything personal — all watches, results, saved logins, chat history, and settings — and restarts the app like a brand-new install. The program itself (and the AI models) stay installed. This cannot be undone.
